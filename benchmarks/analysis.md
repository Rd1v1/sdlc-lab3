# LAB 3 — фактический анализ

## Цель

Сравнить цену проверки хэша, сложность пространства кандидатов и влияние потоков.

## Методика

perf_counter; прогрев verifier вне замера; одинаковые кандидаты для четырёх алгоритмов; повторы и медианы. CSV содержит каждый прогон. Генерация тестового хэша не входит в время перебора.

## Тестовое окружение

2026-09-26T09:30:48.868409+00:00; Windows-11-10.0.26200-SP0; Python 3.13.0; CPU AMD64 Family 23 Model 113 Stepping 0, AuthenticAMD; logical CPUs 12.

## Параметры

bcrypt cost=10, фиксированная учебная salt; Argon2id m=65536 KiB, t=3, p=2, salt=saltsalt. Фиксированные соли нужны только для воспроизводимости учебных векторов. L3 опубликованные easy/medium отдельно проверяются тестами; неизвестные hard plaintext не заявляются.

## Сравнение типов хэша

Сопоставляйте строки одного scenario и workers. MD5/SHA-1 проверяются дёшево; bcrypt и Argon2id намеренно увеличивают стоимость проверки. Для скорости быстрых хэшей используйте fast4/fast5: 3 кандидата дают прежде всего шум таймера и запуска.

## Влияние сложности пароля

base → length2 → length3: 3, 9, 27 кандидатов при алфавите abc; length2 → alphabet4: 9 → 16; position_first отличается от length2 только позицией (1 вместо 9). Для фиксированной длины пространство равно A**L, для диапазона длин — сумме A**L. При ранней находке время зависит от позиции, а не только от длины. Сравнение workers=1/2 использует реальные попытки: потоки могут закончить уже начатые проверки.

## Ограничения эксперимента

Это ограниченный CPU/Python эксперимент, не оценка стойкости реальных учётных записей. Windows power policy, фоновые процессы, GIL и KDF internal threads влияют на результат. Большие неизвестные hard/very-hard хэши не взламывались. Из микросценария нельзя выводить пиковую скорость hashcat. Сравниваются wall times конкретного набора.

## Вывод

Увеличение алфавита/длины растит число проверок, а KDF увеличивает цену каждой проверки. Вывод об ускорении потоками делайте по медианам одного scenario: overhead может перевесить параллелизм.
