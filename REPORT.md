# LAB 3 — сравнение скорости: Моё приложение и hashcat

Замеры: 2026-10-10T07:58:43.221524+00:00. Три повтора каждого алгоритма, медианы; все 12 запусков hashcat нашли пароль.

Окружение: Windows-11-10.0.26200-SP0; Python 3.13.0; CPU AMD64 Family 23 Model 113 Stepping 0, AuthenticAMD; логических процессоров: 12.

Моё приложение: один CPU-поток, интерфейс прогресса отключён. Hashcat 7.1.2: NVIDIA GeForce RTX 4070 SUPER, OpenCL 3.0, драйвер 591.86. Устройство использует OpenCL fallback: CUDA RTC не установлен; системные зависимости не менялись.

## Сводная таблица скорости: Моё приложение и hashcat

Сценарий base: алфавит abc, длина 1, пароль c, 3 кандидата. В таблице медианы повторов; «Моё приложение» использует минимальное число воркеров из этого отчёта. Время приложения «Моё приложение» включает создание и завершение воркеров; время hashcat включает запуск, инициализацию устройства и выполнение поиска. Скорость приложения «Моё приложение» — фактические проверки / время. Эффективная скорость задания hashcat — бюджет кандидатов N / полное время; число реально обработанных GPU кандидатов отдельно не измерялось.

| Алгоритм | Моё приложение: режим / воркеры | Повторы: Моё приложение / hashcat | Моё приложение, с | Моё приложение, проверок/с | Hashcat, с | Hashcat, N/с по wall time |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| md5 | threads / 1 | 3 / 3 | 0.000302300 | 9923.92 | 2.483962 | 1.208 |
| sha1 | threads / 1 | 3 / 3 | 0.000491600 | 6102.52 | 2.394979 | 1.253 |
| bcrypt | threads / 1 | 3 / 3 | 0.166995700 | 17.96 | 10.425126 | 0.288 |
| argon2id | threads / 1 | 3 / 3 | 0.275684000 | 10.88 | 3.374385 | 0.889 |

bcrypt: cost=10. Argon2id: m=65536 KiB, t=3, p=2. Сравниваются одинаковые учебные хэши и наборы кандидатов. На трёх кандидатах доминируют накладные расходы: таблица не доказывает, что Python быстрее GPU на большом переборе. н/д означает отсутствие успешного сопоставимого замера.

## Как читать результаты

Для приложения «Моё приложение» скорость вычислена как фактическое число проверок / elapsed_seconds. Для hashcat указано N / elapsed_seconds, где N=3 — размер переданного wordlist. В каждой колонке берётся медиана трёх индивидуальных скоростей, а не отношение отдельно усреднённых величин.

На таком коротком поиске запуск hashcat занимает основную часть времени. Эти числа описывают скорость выполнения конкретного задания целиком; пиковая скорость GPU в H/s и производительность на больших диапазонах в этом эксперименте не измерялись.

## Воспроизведение

Из корня репозитория после setup.ps1 и setup-tools.ps1:

```powershell
.venv/Scripts/python.exe -m lab3.src.benchmark --smoke --repeats 3 --backend threads --workers 1 --hashcat --hashcat-path .tools/hashcat/hashcat-7.1.2/hashcat.exe --output artifacts/hashcat-summary
```

Исходные замеры: [JSON](reports/comparison-results.json), [прогоны приложения «Моё приложение»](reports/comparison-results.csv), [прогоны hashcat](reports/hashcat-runs.csv). JSON также содержит параметры хэшей и вывод hashcat -I. Время генерации хэшей и wordlist не включено в поисковый таймер.
