# LAB 3 — сравнение скорости: Моё приложение и hashcat

Оба инструмента измерены на CPU в одном контейнере с ограничением на один логический процессор. Hashcat использует CPU OpenCL (PoCL).

## Сравнение времени поиска пароля

Одинаковое задание: проверить варианты a, b, c и найти пароль c. В таблице медианное время успешных запусков. Меньше время — быстрее выполнено это задание. У приложения учтены создание воркеров и поиск; у hashcat — запуск, подготовка вычислительного устройства и поиск.

| Алгоритм | Вариантов пароля в наборе | Моё приложение: время, с | Hashcat: время, с |
| --- | ---: | ---: | ---: |
| MD5 | 3 | 0.000663 | 2.710739 |
| SHA-1 | 3 | 0.000319 | 2.739516 |
| bcrypt | 3 | 0.177463 | 22.432937 |
| Argon2id | 3 | 0.514143 | 5.048780 |

Режим приложения: потоки; воркеров: 1. Для каждого алгоритма запусков приложения: 3; запусков hashcat: 3.

## Скорость выполнения задания с учётом запуска

Здесь скорость = число вариантов пароля в наборе ÷ полное время выполнения. Для обоих инструментов используется одна формула. Это показывает, сколько кандидатов приходится на секунду общего времени, включая подготовку инструмента.

| Алгоритм | Моё приложение: кандидатов/с | Hashcat: кандидатов/с |
| --- | ---: | ---: |
| MD5 | 4526.63 | 1.107 |
| SHA-1 | 9404.68 | 1.095 |
| bcrypt | 16.90 | 0.134 |
| Argon2id | 5.83 | 0.594 |

Это эффективная скорость короткого задания, а не скорость устройства во время самого перебора. На трёх кандидатах большую часть времени hashcat занимает подготовка. Например, для MD5: 3 варианта ÷ полное время hashcat. Из этой таблицы нельзя сделать вывод о скорости инструментов на большом наборе.

bcrypt: cost=10. Argon2id: m=65536 KiB, t=3, p=2. «Нет замера» означает отсутствие успешного сопоставимого запуска.

## Воспроизведение

Из корня репозитория с запущенным Docker Desktop (Linux engine):

```powershell
powershell -ExecutionPolicy Bypass -File scripts/benchmark-cpu.ps1 -Repeats 3
```

Исходные замеры: [JSON](reports/comparison-results.json), [прогоны приложения «Моё приложение»](reports/comparison-results.csv), [прогоны hashcat](reports/hashcat-runs.csv). JSON содержит подтверждение CPU-устройства и параметры запуска. Генерация хэшей, wordlist и сборка контейнера не входят в таймер поиска.
