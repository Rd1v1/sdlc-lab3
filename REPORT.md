# LAB 3 — сравнение времени: без словаря и с rockyou.txt

Оба приложения выполняют хеширование на одной GPU — NVIDIA GeForce RTX 4070 SUPER — через OpenCL. Замеры выполнены напрямую в Windows. В каждой ячейке — медиана 3 запусков для одного и того же учебного пароля `123456`.

| Алгоритм | Моё приложение: без словаря, с | Моё приложение: rockyou.txt, с | Hashcat: без словаря, с | Hashcat: rockyou.txt, с |
| --- | ---: | ---: | ---: | ---: |
| MD5 | 0.676023 | 0.652473 | 2.069535 | 1.511210 |
| SHA-1 | 0.657589 | 0.678246 | 1.963563 | 1.639994 |
| bcrypt | 1.443339 | 1.518265 | 9.489278 | 13.348340 |
| Argon2id | 0.919117 | 0.816830 | 2.878758 | 2.409252 |

Без словаря: известен префикс `12345`, перебирается последняя цифра от 0 до 9 (10 вариантов, маска `12345?d`). Моё приложение генерирует варианты в памяти; hashcat использует настоящий режим маски `-a 3`, без файла кандидатов. Этот замер относится к указанной маске, а не к полному перебору всех шестизначных паролей.

Со словарём: используется полный исходный `rockyou.txt` — 14,344,391 строк; `123456` находится в строке 1. Моё приложение читает словарь потоково, hashcat работает в режиме `-a 0`. Поиск останавливается после находки: время не означает проверку всех строк.

Для обоих инструментов измеряется время отдельного процесса от запуска до завершения: подготовка OpenCL, чтение кандидатов, передача данных и поиск включены. Моё приложение отправляет пакеты до 16 кандидатов на GPU; завершает уже начатый пакет перед проверкой результата. Параметры хэшей и наборы кандидатов одинаковы; GPU-запуски идут последовательно. Скачивание словаря, проверка его контрольной суммы и генерация хэшей выполняются до замера.

bcrypt: cost=10. Argon2id: m=65536 КиБ, t=3, p=2. Соли одинаковы для обоих инструментов. На коротком поиске подготовка hashcat существенно влияет на время; таблица не оценивает пиковую скорость GPU.

## Отдельный запуск инструментов

Таблица содержит результаты ранее выполненных замеров; исходные данные сохранены без изменения. В текущей версии приложения встроенное сравнение удалено. Для новых замеров запускайте моё приложение и hashcat отдельно по [инструкции в README](README.md). Предыдущий эксперимент проверял контрольную сумму словаря до измерения; текущий самостоятельный GPU-поиск включает эту проверку при чтении словаря, поэтому новые времена могут отличаться.

Исходные замеры: [JSON](reports/comparison-results.json), [Моё приложение](reports/comparison-results.csv), [hashcat](reports/hashcat-runs.csv). JSON содержит SHA-256 словаря, позицию пароля, подтверждение GPU-устройства и команды атак. Словарь хранится в `.tools/wordlists` и не включён в Git.

GPU-бэкенд приложения управляет OpenCL напрямую через PyOpenCL. Криптографические примитивы заимствованы из hashcat 7.1.2 под MIT; [лицензия](lab3/src/kernels/vendor/LICENSE.txt) и [происхождение файлов](lab3/src/kernels/vendor/ORIGIN.json) сохранены. Генерация кандидатов, чтение словаря, передача буферов, запуск ядер и проверка результата реализованы в приложении; приложение не вызывает исполняемый файл hashcat для своего поиска.
