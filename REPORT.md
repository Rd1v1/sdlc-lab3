# LAB 3 — сравнение времени: без словаря и с rockyou.txt

Оба инструмента измерены на CPU в одном контейнере, ограниченном одним логическим процессором. В каждой ячейке — медиана 3 запусков для одного и того же учебного пароля `123456`.

| Алгоритм | Моё приложение: без словаря, с | Моё приложение: rockyou.txt, с | Hashcat: без словаря, с | Hashcat: rockyou.txt, с |
| --- | ---: | ---: | ---: | ---: |
| MD5 | 0.000679 | 0.003434 | 3.501889 | 3.004676 |
| SHA-1 | 0.000534 | 0.002937 | 3.457065 | 2.547502 |
| bcrypt | 0.415790 | 0.064100 | 14.370611 | 15.522034 |
| Argon2id | 1.211787 | 0.172770 | 5.768981 | 3.308062 |

Без словаря: известен префикс `12345`, перебирается последняя цифра от 0 до 9 (10 вариантов, маска `12345?d`). Моё приложение генерирует варианты в памяти; hashcat использует настоящий режим маски `-a 3`, без файла кандидатов. Этот замер относится к указанной маске, а не к полному перебору всех шестизначных паролей.

Со словарём: используется полный исходный `rockyou.txt` — 14,344,391 строк; `123456` находится в строке 1. Моё приложение читает словарь потоково, hashcat работает в режиме `-a 0`. Поиск останавливается после находки: время не означает проверку всех строк.

Моё приложение использует один поток. Время включает создание воркера, чтение кандидатов и поиск; у hashcat также учтены запуск процесса, подготовка OpenCL и индексация словаря. Скачивание словаря, проверка его контрольной суммы, генерация хэшей и сборка контейнера выполняются до замера.

bcrypt: cost=10. Argon2id: m=65536 КиБ, t=3, p=2. Соли одинаковы для обоих инструментов. На коротком поиске подготовка hashcat существенно влияет на время; таблица не оценивает пиковую скорость CPU.

## Нужен ли Docker для LAB 3

По сохранённым требованиям LAB 3 Docker не обязателен: нужны собственный перебор, анализ скорости и сравнение с профессиональным инструментом. Приложение и тесты запускаются через локальную `.venv`. Docker требуется только для воспроизведения этих CPU-замеров: в текущей Windows-конфигурации hashcat не видит CPU OpenCL, поэтому оба инструмента запускаются вместе с PoCL в контейнере. При установленном CPU OpenCL можно работать без Docker. Актуальная страница задания на момент проверки недоступна.
